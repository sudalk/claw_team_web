# ClawTeam Web 操作指南

## 团队管理

### 1. 创建团队
**入口**: 首页右上角 **+ 创建团队**

填写团队名称和描述（可选）。如果指定 **工作目录**，所有 Worker 默认在此目录下工作。

### 2. 团队概览（首页卡片）
进入团队后，每个卡片显示：
- 成员数量 / Worker 数量 / 任务总数
- 进度条（已完成任务占比）
- **管理** 按钮进入团队详情
- **删除** 按钮可删除整个团队

---

## 任务管理

### 3. 任务看板
进入团队后默认显示 **任务** 标签页，四列看板：
- **待办** — 新建的任务
- **进行中** — 被分配并点击执行的
- **已完成** — 任务完成
- **阻塞** — 有未完成依赖的任务

### 4. 新建任务
看板页右上角 **+ 新任务**，弹出表单：

| 字段 | 说明 |
|------|------|
| 任务标题 | 必填，简洁描述要做什么 |
| 详细描述 | 选填，给 Worker 的具体指令 |
| 优先级 | 低/中/高，影响排序 |
| 分配给 | 选填，直接指定某个 Worker |
| 依赖任务 | 选填，选中后此任务被阻塞直到所选任务完成 |

> **依赖用法**：例如先建"实现基础功能"任务，再建"写测试用例"任务并将前者设为依赖，则测试任务自动阻塞直到基础功能完成。

### 5. 编辑任务
点击任务卡片右侧 **⋮** 菜单 → **编辑**，可修改标题/描述/优先级/分配。

### 6. 移动/删除任务
点击任务卡片右侧 **⋮** 菜单：
- **移动到** — 切换状态列（pending / 进行中 / 已完成 / 阻塞）
- **删除** — 删除任务

## Worker 管理

### 7. 添加 Worker
**入口**: 顶部 **+ 添加 Worker** 按钮，或 **Worker** 标签页。

| 字段 | 说明 |
|------|------|
| Worker 名称 | 如 coder、tester |
| 角色 | 通用 / 编码助手 / 测试助手 / 代码审查 |
| AI 引擎 | Claude / Codeflicker / Codex / Gemini / Nanobot |
| 运行方式 | **Tmux**（可视化监控，推荐）/ 后台运行（无界面） |
| 工作目录 | 留空则使用团队默认目录 |
| 执行模式 | **自动**（Worker 自动接收任务）/ **手动**（需点击执行触发） |

### 8. 分配任务
Worker 空闲时卡片上显示紫色 **📋 分配任务** 按钮，点击选择要分配的任务。

> 或者在任务卡片右侧 **⋮** → **分配 Worker**，选择具体 Worker。

### 9. 执行任务
任务分配后，Worker 卡片出现 **▶️ 执行** 按钮，点击触发 Worker 开始工作。

- **Tmux 后端**：会自动向 tmux session 发送任务指令，可打开 tmux 窗口实时观察 Worker 进展
- **后台运行**：Worker 在后台执行，无可视化界面

### 10. 标记完成 / 失败
Worker 执行完成后：
- **✅ 完成** — 将任务标记为已完成
- **❌ 失败** — 将任务标记为失败

## 实时监控

### 11. 通过 tmux 可视化
Tmux 后端的 Worker 运行在 tmux session `clawteam-{团队名}:{Worker名}`，可用以下方式查看：

```bash
# 查看所有 Worker 窗口
tmux list-windows -t clawteam-{团队名}

# 合并所有窗口为平铺视图
clawteam board attach {团队名}
```

### 12. 通过页面实时更新
页面已接入 SSE 实时推送：
- 任务状态变化 → 看板自动刷新
- Worker 状态变化 → 卡片自动更新
- 收到消息 → 消息列表自动刷新

无需手动刷新页面。

---

## 消息中心

### 13. 发送消息
**Worker** 标签页 → 找到 Worker → 切换到 **消息** 标签页。

在底部表单输入 Worker 名称和消息内容，点击 **发送**。

> 注意：Worker 需要主动检查 inbox 才能收到消息（可通过 tmux 向 Worker 发送指令触发）。

## 完整示例流程

```
1. 创建团队 "algo-dev"，工作目录指定为项目路径
2. 创建任务 A："实现倒排索引算法"
3. 创建任务 B："编写单元测试"，依赖任务 A
   → B 任务自动显示为 "阻塞" 状态
4. 添加 Worker "dev-1"，Tmux 模式
5. 给 dev-1 分配任务 A，点击执行
6. dev-1 开始工作，完成后标记任务 A 为完成
   → 任务 B 自动解除阻塞变为 "待办"
7. 给 dev-1 分配任务 B，执行
8. 任务 B 完成
```

## 快捷操作

| 操作 | 入口 |
|------|------|
| 修改团队工作目录 | 团队页 → **设置** 标签 |
| 查看 Worker 执行进度 | Worker 标签 → 卡片内进度条 |
| 终止 Worker | Worker 标签 → **终止** 按钮 |
| 快速刷新 | 切换标签页（触发数据重载） |
